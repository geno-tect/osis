5. KALAU MAU GANTI FONT
======================================================================

Ada tiga tempat font. Jangan cuma ganti satu.

A. Halaman Breeze: login, register, dashboard, profile
   Sekarang memakai font Figtree dari Bunny Fonts.

   1. Buka resources/views/layouts/app.blade.php, cari:

      <link href="https://fonts.bunny.net/css?family=figtree:400,500,600&display=swap" rel="stylesheet" />

   2. Buka resources/views/layouts/guest.blade.php, ganti link yang sama.

   3. Buka tailwind.config.js, ganti:

      fontFamily: {
          sans: ['Figtree', ...defaultTheme.fontFamily.sans],
      },

   4. Jalankan:

      npm run build

   5. Hard refresh browser: Ctrl + F5.

   Kalau font baru dari Google Fonts, ganti URL-nya dengan link Google Fonts
   yang sesuai, lalu samakan nama font di tailwind.config.js.

B. Halaman OSIS
   Sekarang memakai Georgia untuk judul dan system UI untuk isi.

   Buka public/css/osis.css, di bagian paling atas:

   --font-display: Georgia, 'Times New Roman', serif;
   --font-body: system-ui, -apple-system, 'Segoe UI', Roboto, Arial, sans-serif;

   Ganti dua baris itu. Tidak perlu npm run build, cukup simpan dan
   hard refresh.

   Kalau mau pakai font dari internet, tambahkan <link> font di
   resources/views/layouts/osis.blade.php, lalu tulis nama fontnya di
   dua variabel itu.

C. Landing page /
   resources/views/welcome.blade.php memakai Instrument Sans dan punya
   blok CSS inline yang sangat panjang. Ini terpisah dari halaman lain.
   Kalau mau seragam, ubah link font di file itu. Tapi hati-hati, file ini
   paling ribet dan bukan prioritas untuk belajar.

6. KALAU MAU UBAH CSS
======================================================================

A. Halaman OSIS
   Semua di public/css/osis.css.

   Di atas ada variabel warna:

   --paper: #f5f1e7;
   --surface: #fffcf5;
   --ink: #1d2926;
   --muted: #5d6a65;
   --accent: #0f5a49;
   --accent-deep: #0a4135;
   --focus: #9a6a1e;
   --radius: 4px;

   Kalau mau ganti tema, cukup ubah variabel ini. Contoh:

   --accent: #1d4ed8;
   --accent-deep: #1e3a8a;

   Bagian lain:

   - .site-header, .site-nav: navbar.
   - .page-head, .lede: judul halaman.
   - .btn, .btn--primary, .btn--ghost: tombol.
   - .alert--success, .alert--error: pesan.
   - .table-wrap, .data-table: tabel.
   - .form-card, .field, .field-row: form.
   - Bagian bawah ada media query untuk layar kecil.

   Setelah simpan, cukup Ctrl + F5. Tidak ada build.

B. Halaman Breeze/Tailwind
   Class Tailwind ada langsung di file Blade. Contoh di dashboard.blade.php:

   class="rounded-lg border border-gray-200 bg-white p-5 dark:border-gray-700 dark:bg-gray-800"

   Kalau mau ganti warna, ganti class-nya, misalnya bg-gray-800 jadi
   bg-emerald-800. Setelah itu:

   npm run build

   Kalau ingin warna khusus di luar palette Tailwind, baru edit
   tailwind.config.js.

8. WARNING YANG PALING PENTING
======================================================================

A. Blade

   - Jangan hapus @vite, {{ $slot }}, @include('layouts.navigation'),
     atau @yield('content'). Halaman bisa blank atau error.
   - Jangan hapus @csrf di form. Form akan ditolak.
   - Di osis/edit.blade.php, jangan hapus @method('PUT'). Update tidak
     akan jalan.
   - Jangan ubah nama field id_osis, nama, kelas, jurusan, sekbid tanpa
     mengubah validasi di controller.
   - Jangan hapus x-data, @click, atau x-show di navigation.blade.php.
     Dropdown dan menu mobile akan mati.

B. Izin dan role

   - Jangan hapus @if (Auth::user()->isAdmin()) di navigasi. User akan
     melihat link Dashboard lagi.
   - Jangan hapus @if ($isAdmin) di osis/index.blade.php. User akan
     melihat tombol tambah/edit, walaupun backend tetap menolak.
   - Jangan hapus middleware admin dari route create/store/edit/update.
     Controller tidak mengecek role sendiri.
   - Jangan ubah nilai role admin di database menjadi teks lain.
     isAdmin() bergantung pada string itu.

C. Database

   - Jangan edit migration lama setelah dijalankan. Buat migration baru.
   - Jangan jalankan php artisan migrate:fresh. Semua data OSIS dan user
     akan hilang.
   - Jangan jalankan php artisan db:seed berkali-kali. Bisa bentrok email
     test@example.com.
   - Kalau mau menambah kolom, buat migration baru lalu php artisan migrate.

D. Build dan asset

   - Jangan edit public/build/manifest.json atau file CSS/JS di dalam
     public/build.
   - Setelah mengubah Tailwind atau Blade, jalankan npm run build.
   - Kalau CSS terlihat tidak berubah, hard refresh Ctrl + F5.
   - Kalau masih tidak berubah, jalankan:

     php artisan view:clear
     php artisan optimize:clear

E. Environment

   - Jangan ganti APP_KEY di .env. Session dan data terenkripsi bisa rusak.
   - Setelah mengubah .env, jalankan php artisan config:clear dan restart
     php artisan serve.

F. Tampilan

   - Kalau mengganti warna, cek kontras teks. Tombol dengan teks putih
     butuh background yang cukup gelap.
   - Halaman Breeze punya mode gelap lewat class dark:. Kalau mengganti
     warna terang, cek juga versi gelapnya.
   - Halaman OSIS belum punya mode gelap.
   - Tabel OSIS memang bisa discroll ke samping di HP. Itu disengaja lewat
     .table-wrap.
   - Iconoir dimuat lewat CDN @main, belum dikunci versinya. Kalau CDN
     berubah, icon bisa hilang. Untuk produksi, sebaiknya pakai versi
     tertentu atau simpan file CSS-nya sendiri.

G. File yang masih dipakai

   - components/application-logo.blade.php masih dipakai di halaman login.
     Jangan hapus.
   - components/dashboard-summary.blade.php dipakai dashboard admin.
     Jangan hapus sembarangan.
   - layouts/guest.blade.php hanya untuk login/register. Mengubah
     layouts/app.blade.php tidak akan mengubah halaman login.
