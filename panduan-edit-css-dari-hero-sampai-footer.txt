PANDUAN EDIT CSS PROJECT OSIS
============================

CATATAN: Dokumen ini snapshot lama. Nama file CSS dan jumlah barisnya sudah
berubah (navbar.css kini navigasi.css). Lihat README.md untuk struktur yang
berlaku saat ini.

Tujuan
------
Panduan ini menunjukkan file CSS mana yang mengatur tiap halaman dan bagian visual, dari hero sampai footer, cara menemukan selector, lalu cara mengubah warna, ukuran, jarak, gambar, dan tampilan mobile tanpa mengubah fungsi aplikasi.

PETA TIGA FILE CSS
------------------
1. public/css/beranda.css (2.478 baris)
   Dipakai oleh layouts/public.blade.php. Mengatur beranda publik, header publik, hero, agenda, tentang/visi-misi, struktur dan anggota, berita, ajakan aspirasi, footer publik, halaman form aspirasi, halaman detail berita, serta aturan responsive halaman publik.

2. public/css/navbar.css (331 baris)
   Dipakai oleh layouts/osis.blade.php bersama osis.css. Mengatur header/navbar khusus halaman manajemen OSIS: logo dan nama brand, tautan dashboard, tombol profil/logout, tombol navigasi, warna mode gelap, dan responsive header.

3. public/css/osis.css (514 baris)
   Dipakai oleh layouts/osis.blade.php bersama navbar.css. Mengatur halaman tambah/edit anggota: latar, kontainer, judul, tombol, alert, tabel, form, upload foto, dan footer kecil halaman admin.

PENTING: dashboard admin memakai layouts/app.blade.php dan resources/css/app.css/Tailwind. Tampilan dashboard tidak terutama diatur oleh tiga file di atas. Untuk mengubah dashboard, cari class Tailwind langsung di resources/views/dashboard.blade.php atau components/dashboard-summary.blade.php.

CARA MENEMUKAN BAGIAN YANG MAU DIEDIT
--------------------------------------
1. Buka halaman yang terlihat di browser.
2. Klik kanan bagian itu > Inspect/Periksa. Di panel Elements, pilih elemen visualnya.
3. Lihat nama class HTML, misalnya hero-figure atau event-card.
4. Cari nama class tersebut dengan Ctrl+F di file CSS atau jalankan rg -n "hero-figure" public/css/beranda.css.
5. Edit deklarasi CSS pada selector yang cocok. Selector class memakai titik: .hero-figure. Selector ID memakai #: #struktur.
6. Perhatikan aturan responsive di bagian bawah file: nilai desktop dapat ditimpa pada breakpoint mobile.
7. Simpan, refresh browser. Jika belum berubah, lakukan hard refresh (Ctrl+F5) untuk mengosongkan cache CSS.

Jangan menambahkan titik pada atribut HTML. Di HTML ditulis class="hero-figure", di CSS ditulis .hero-figure.

CARA MENGUBAH HAL YANG UMUM
---------------------------
Ganti warna satu bagian:
  .hero { background: #warna-baru; }
Untuk warna seluruh tema, cari variabel di :root dan ubah variabel terkait.

Ganti jarak dalam satu komponen:
  .hero-grid { gap: 3rem; }
Ubah properti yang sudah ada sebelum menambahkan duplikat baru. Jika ada dua deklarasi selector sama, deklarasi yang lebih akhir dapat menang.

Ganti ukuran judul:
  .hero h1 { font-size: clamp(2.5rem, 5vw, 4.5rem); }
Gunakan clamp agar ukuran tetap menyesuaikan lebar layar.

Atur crop gambar:
  .hero-frame__image { object-fit: cover; object-position: center 35%; }
Jika gambarnya salah, ubah sumber gambar di Blade/data, bukan properti CSS.

Atur jumlah kolom:
  .news-grid { grid-template-columns: repeat(3, minmax(0, 1fr)); }
Pastikan ada aturan di media query HP agar kolom tidak terlalu sempit.

Contoh penyesuaian mobile:
  @media (max-width: 720px) {
      .hero-grid { grid-template-columns: 1fr; }
      .hero-figure { max-width: 28rem; }
  }
Gunakan breakpoint yang sudah ada bila mungkin supaya aturan responsive tetap terkumpul.

CARA KERJA AMAN
---------------
1. Tentukan halaman dan bagian: publik beranda/aspirasi/berita -> beranda.css; form anggota -> osis.css; navbar form anggota -> navbar.css; dashboard -> app.css/Tailwind.
2. Cari class pada Blade atau lewat Inspect. Jangan menebak nama selector.
3. Ubah satu kelompok kecil properti, simpan, lalu refresh halaman yang sesuai.
4. Periksa desktop dan lebar HP. Coba juga hover/focus, tab sekbid, menu mobile, dan error/success form jika perubahan menyentuh status tersebut.
5. Bila perubahan tidak terlihat: pastikan file CSS benar-benar dimuat oleh layout; hard refresh; periksa apakah ada deklarasi lain atau media query yang menimpa; periksa typo selector.
6. Hindari menghapus outline focus, aturan [hidden], state aria-selected, atau prefers-reduced-motion. Aturan ini berpengaruh ke aksesibilitas dan interaksi.
7. Untuk teks, data, foto, tautan, atau jumlah item, edit Blade/config/database melalui fungsi yang sesuai. CSS mengatur presentasi saja.
